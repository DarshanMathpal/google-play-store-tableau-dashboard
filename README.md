# Google Play Store Analysis Dashboard

## Overview

This Tableau project explores Google Play Store app data to identify patterns in app performance, user engagement, pricing strategies, and category trends.

The dashboard is designed to help understand what drives installs, ratings, and marketplace success across different types of apps.

## Tools & Skills

* Tableau
* Dashboard Design
* Data Visualization
* Exploratory Data Analysis

## Data Source

The project uses a Google Play Store dataset containing app-related metrics and attributes, including:

* App
* Category
* Rating
* Reviews
* Installs
* Price
* Free / Paid Type
* Content Rating
* Genre
* Last Updated Date

## What the Dashboard Covers

* Most Installed Apps
* Category Performance Comparison
* Ratings Analysis
* User Review Trends
* Free vs Paid App Distribution
* Price Insights
* Genre-Level Trends
* Update Frequency Analysis

## Key Findings

* Free apps make up the majority of available apps.
* Categories like tools, games, and communication attract large install volumes.
* Apps with stronger engagement often receive more reviews.
* Pricing models differ widely depending on category and audience.
